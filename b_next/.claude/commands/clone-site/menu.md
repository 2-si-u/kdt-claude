# 리스트 클론 코딩하기

`$1`에 지정된 예시(FewShot) 이미지를 참고해서, 아래 리스트 목록을 클론 코딩해 줘.

## 1. 입력

- `$1`: 참고할 예시 이미지 경로
  - 이미지의 레이아웃, 색상, 간격, 텍스트 등을 최대한 그대로 재현해 줘.
- `$ARGUMENTS`: 리스트 목록
  - 예시 이미지에 들어갈 항목 내용을 그대로 사용해 줘.

## 2. 구현

- 이미지와 동일한 리스트 화면을 만드는 데 집중해 줘.
- 정적인 HTML/CSS 구조와 레이아웃을 우선으로 해 줘.

## 주의 사항

- 예시 이미지나 리스트 목록에 없는 항목을 임의로 추가하지 마.
- `$1` 이미지가 없으면 진행하지 말고 알려 줘.
