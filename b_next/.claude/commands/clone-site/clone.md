# 클론 코딩 작업

예시 이미지를 참고해서 화면을 최대한 똑같이 클론 코딩해줘.

- 예시(Few-shot) 이미지: `$1`

---

## 0. 사전 확인

- `$1`이 비어 있거나 이미지를 열 수 없으면 **작업을 멈추고** 이미지 경로를 다시 달라고 요청한다.
- 현재 프로젝트에 이미 쓰고 있는 기술 스택(React, Vue, Next.js 등)이 있으면 그것을 따른다.
- 스택이 없으면 **HTML + CSS + JavaScript**로 만든다.

## 1. 이미지 분석

코드를 쓰기 전에 이미지를 보고 아래 내용을 먼저 정리한다.

- **레이아웃**: 헤더 / 본문 / 사이드바 / 푸터 등 전체 구조와 영역 배치
- **컴포넌트**: 버튼, 카드, 입력창, 네비게이션, 리스트 등 반복되는 요소
- **스타일**: 색상(가능하면 HEX 값), 글꼴, 글자 크기, 여백, 모서리 둥글기, 그림자
- **텍스트**: 이미지에 보이는 문구는 그대로 옮긴다.

## 2. 구현

- 분석한 구조대로 컴포넌트 단위로 나눠서 만든다.
- 색상·여백 등 반복 값은 변수(CSS 변수 등)로 정리한다.
- 이미지·아이콘·로고는 실제 파일이 없으면 **같은 크기의 placeholder**로 대신한다.
- 반응형: 이미지 기준 화면 크기를 우선 맞추고, 모바일에서도 깨지지 않게 한다.
- 이미지에서 알 수 없는 동작(클릭 후 화면 등)은 임의로 만들지 않는다.

## 3. 비교 및 수정

- 완성한 화면을 예시 이미지와 나란히 비교한다.
- 레이아웃, 색상, 간격, 글자 크기 순서로 다른 부분을 찾아 수정한다.

---

## 완료 후 보고

작업이 끝나면 아래 내용을 짧게 알려줘.

- 사용한 기술 스택과 생성한 파일 목록
- 실행 방법
- 예시 이미지와 다르게 처리한 부분 (placeholder로 대신한 이미지 등)
